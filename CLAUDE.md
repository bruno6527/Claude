# Consignes du projet

## Git
- Une fois les changements commités et poussés sur la branche de travail, créer
  systématiquement une pull request vers `main` puis la fusionner, sans redemander
  à l'utilisateur.
- Si la pull request précédente est déjà fusionnée, repartir de `main` à jour pour la
  suite du travail (merge de `main` dans la branche, pas de réécriture d'historique).
